Veritabanı Backend Yetkilendirme Veri Güvenliği

02 tamamlandı

Facial Image Warping

MediaPipe FaceMesh kullanılarak yüz üzerinde 468 noktalı landmark tespiti yapan ve bu verilerle dijital warping işlemleri gerçekleştiren FastAPI tabanlı bir web uygulaması. Arayüz Figma ile tasarlandı; sonuçlar MSE, PSNR ve SSIM metrikleriyle analiz edilerek proje başarıyla tamamlandı.

FastAPI Python MediaPipe Figma

Web Algoritma Gerçek Zamanlı Frontend
